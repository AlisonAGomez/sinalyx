# Relatos de segurança

Use o relato privado de vulnerabilidades do GitHub quando o recurso estiver habilitado. Se a opção estiver indisponível, solicite ao mantenedor um canal privado antes de enviar os detalhes. Mantenha informações sensíveis fora de issues, pull requests e comentários públicos.

Inclua a versão ou o commit afetado, o componente, as condições necessárias e o impacto observado. Use dados sintéticos. Remova credenciais, tokens, logs reais e identificadores pessoais de qualquer anexo.

Consulte [Segurança do Sinalyx](docs/security.md) para orientações de configuração e tratamento de dados.
